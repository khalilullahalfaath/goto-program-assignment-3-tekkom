\section{Problem 3.1 -- \textit{infloop}}

Akan dibuktikan bahwa $\textit{infloop}(x_1)\uparrow$ untuk semua
$x_1\in\mathbb{N}$ adalah GOTO-computable. Karena fungsi tidak
terdefinisi di seluruh domain, program harus tidak pernah berhenti untuk
input apa pun.

\textbf{Program GOTO.} Program ditunjukkan pada Gambar~\ref{fig:goto31},
berinput $k=1$ dengan $m=1$.

\textbf{Bukti.} Klaim: setelah berapa pun langkah berhingga, label aktif
selalu $L_1$ atau $L_2$. Basis: eksekusi mulai dari $L_1$. Langkah
induktif: dari $L_1$ (bukan lompatan/\texttt{HALT}), kontrol jatuh ke
$L_2$; dari $L_2$ (\texttt{GOTO L1}), kontrol kembali ke $L_1$. Jadi
label aktif selalu $L_1$ atau $L_2$; program tidak pernah menemui
\texttt{HALT} dan tidak pernah melewati baris terakhir. Program tidak
pernah berhenti untuk $x_1$ berapa pun, persis definisi
$\textit{infloop}$. $\blacksquare$

\section{Problem 3.2 -- GOTO $\to$ WHILE}

Diberikan GOTO program berikut; program berinput $k=2$, $m=2$, $n=9$
baris, dan $L_8$ (\texttt{GOTO L2}) tidak pernah dituju (\textit{dead
code}) namun tetap diterjemahkan agar skema berlaku umum.

\begin{lstlisting}
L1: IF x1 = 0 THEN GOTO L9;
L2: x0 := x0 + 1;
L3: IF x2 = 0 THEN GOTO L9;
L4: x0 := x0 + 1;
L5: x2 := x2 - 1;
L6: x1 := x1 - 1;
L7: GOTO L1;
L8: GOTO L2;
L9: HALT
\end{lstlisting}

\textbf{Semantik program.} Selama $x_1\neq0$ dan $x_2\neq0$, satu putaran
$L_1$--$L_7$ menambah $x_0$ sebanyak $2$ serta mengurangi $x_1$ dan $x_2$
masing-masing $1$; putaran berulang $\min(x_1,x_2)$ kali. Bila $x_1\leq
x_2$, $L_1$ langsung melompat ke \texttt{HALT} sehingga $x_0=2x_1$; bila
$x_1>x_2$, $L_2$ menambah $x_0$ sekali lagi sebelum $L_3$ melompat,
sehingga $x_0=2x_2+1$. Jadi
$f(x_1,x_2)=2\min(x_1,x_2)+[x_1>x_2]$, fungsi total.

\textbf{Program WHILE} (skema GOTO $\to$ WHILE dengan variabel kontrol
$x_3$; Gambar~\ref{fig:while32}). Setiap statement $S_i$ menjadi blok
\texttt{IF x3=i}, dengan pemetaan: $L_1,L_3$ menjadi lompatan bersyarat
($x_3:=9$ atau $x_3:=i{+}1$), $L_2,L_4$ menambah $x_0$ lalu $x_3:=i{+}1$,
$L_5,L_6$ mengurangi $x_2,x_1$ lalu $x_3:=i{+}1$, $L_7$ menjadi $x_3:=1$,
$L_8$ menjadi $x_3:=2$, dan $L_9$ (\texttt{HALT}) menjadi $x_3:=0$.

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{images/playground.png}
    \caption{Kode Ruby WHILE program Problem 3.2 beserta hasil
    eksekusinya, dijalankan pada \textit{online Ruby playground}
    (\url{https://onecompiler.com/ruby}).}
    \label{fig:while32}
\end{figure}

Hasil eksekusi pada Gambar~\ref{fig:while32} sesuai formula
$f=2\min(x_1,x_2)+[x_1>x_2]$, misalnya $f(5,2)=5$, $f(4,4)=8$, dan
$f(4,9)=8$.

\textbf{Bukti.} (i) GOTO asli selalu berhenti: setiap putaran penuh
mengurangi $\min(x_1,x_2)$ tepat $1$, sehingga setelah paling banyak
$\min(x_1,x_2)+1$ putaran salah satu variabel bernilai $0$ dan terdeteksi
di $L_1$ atau $L_3$, lalu program berhenti. (ii) WHILE hasil terjemahan
mensimulasikan GOTO langkah demi langkah: invariannya, nilai $x_3$ selalu
sama dengan indeks label aktif GOTO dan nilai $x_0,x_1,x_2$ sama pada
kedua program (basis: $x_3=1$ berpadanan dengan mulai di $L_1$; langkah
induktif: karena kondisi $x_3=1,\dots,9$ saling lepas, hanya blok
$P_i$ untuk $i=x_3$ yang aktif dan efeknya persis $S_i$ beserta label
berikutnya). Saat GOTO mencapai $L_9$ (\texttt{HALT}), WHILE mengeksekusi
$x_3:=0$ dan loop utama berhenti dengan nilai $x_0$ yang sama, yaitu
$f(x_1,x_2)$. $\blacksquare$

\section{Problem 3.3 -- WHILE $\to$ GOTO}

Diberikan WHILE program berikut.
\begin{lstlisting}
WHILE x1 != 0 DO
    WHILE x2 != 0 DO
        x0 := x0 + 1;
        x2 := x2 - 1
    END;
    x1 := x1 - 1
END
\end{lstlisting}

\textbf{Semantik program.} Bila $x_1=0$, loop luar tidak dieksekusi dan
$x_0=0$. Bila $x_1>0$, loop dalam memindahkan seluruh nilai awal $x_2$ ke
$x_0$ (hanya efektif pada putaran pertama karena $x_2$ tidak diisi ulang),
lalu $x_1$ dikurangi sampai habis. Jadi
$g(x_1,x_2)=x_2$ untuk $x_1>0$, dan $g(0,x_2)=0$; fungsi total.

\textbf{Program GOTO.} Hasil terjemahan rekursif skema WHILE $\to$ GOTO
ditunjukkan pada Gambar~\ref{fig:goto33}: $L_1$--$L_2$ menguji kondisi
loop luar, $L_2$--$L_5$ adalah terjemahan loop dalam ($L_6$ = ``setelah
loop dalam''), $L_6$--$L_7$ adalah sisa isi loop luar, dan $L_8$ adalah
``setelah loop luar'' (\texttt{HALT}).

\textbf{Verifikasi.} Untuk $x_1=3,x_2=5$: loop dalam menaikkan $x_0$ ke
$5$ sambil menghabiskan $x_2$, lalu $x_1$ dikurangi sampai $0$; hasil
akhir $x_0=5=x_2$, sesuai $g(3,5)=5$. Untuk $x_1=0$, $L_1$ langsung
melompat ke \texttt{HALT} sehingga $x_0=0$.

\textbf{Bukti.} (i) WHILE asli selalu berhenti: loop dalam mengurangi
$x_2$ tepat $1$ tiap iterasi (berhenti setelah $x_2$ iterasi), dan loop
luar mengurangi $x_1$ tepat $1$ tiap iterasi (berhenti setelah $x_1$
iterasi). (ii) GOTO hasil terjemahan ekivalen, dibuktikan dengan induksi
struktural: kasus dasar $x:=x\pm1$ identik; kasus sequencing menempatkan
terjemahan $P_b$ tepat setelah $P_a$; kasus WHILE loop, bila $x=0$ maka
\texttt{IF} langsung melompat ke $L_\ell$ (loop dilewati), dan bila
$x\neq0$ maka isi loop dieksekusi lalu \texttt{GOTO }$L_j$ mengulang
pengujian -- persis semantik \texttt{WHILE}. Karena WHILE asli berhenti,
GOTO hasil terjemahan juga berhenti, dengan nilai $x_0=g(x_1,x_2)$.
$\blacksquare$
